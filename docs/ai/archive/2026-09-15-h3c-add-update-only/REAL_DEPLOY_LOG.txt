## 4) Why the plugin step is not needed on this machine

* ~/.claude/plugins/installed_plugins.json already lists all six enabled plugins
  (context7, chrome-devtools-mcp, pyright-lsp, typescript-lsp, frontend-design,
  clangd-lsp), so the plugin step has nothing to add here.
* The 2026-09-15 stall was that step reaching for the github marketplace
  (anthropics/claude-plugins-official): the CLI sat with no output and no CPU. That is why
  every install now announces itself and is killed after INSTALL_PS1_PLUGIN_TIMEOUT_SEC
  (180s by default).
* Practical default on this machine: -NoPluginInstall. Use the bare command only on a
  machine whose plugins are missing, and run it somewhere you can watch the output.
* 157 *.bak-* files (2.31 MB, written 2026-08/2026-09 by older installers) live under
  ~/.claude and friends. The keep-local-only rule preserves them, so they are never
  reported as [STALE] and nothing prunes them automatically - pruning is a human decision.
